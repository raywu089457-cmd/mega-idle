## 決策(2026-08-17,使用者指定)

**拿掉 TheoTown**,整個遊戲轉換成 Soul's Remnant 可愛繽紛像素風格。
- `docs/THEOTOWN-ART-RULES.md` **廢止**為唯一地圖基準(此文件不含 TheoTown 語法)。
- 全域風格:大頭 Q 版比例 + 高彩糖果色票 + 柔色(非純黑)輪廓 + 明亮高調。
- 原 FF1 黑描邊角色契約、dark-fantasy UI、TheoTown 等角文法,全部由本文件取代。
- 機械規則(地圖拓樸/錨點/迷霧/熱區、存檔 schema、數值)一律**不動**,只改美術格律。

## 全域格律(取代 THEOTOWN / FF1 黑描邊 / dark-UI)

| # | 規則 | 數值/做法 |
|---|---|---|
| G1 | **高彩糖果色票** | 全遊戲主色飽和度 65–90%(比 TheoTown 60–80% 高一檔);校準:糖果粉 `#ff6fae`/陽光黃 `#ffd166`/薄荷 `#7fd8c0`/天空藍 `#6ac8ff` 同檔 |
| G2 | **明亮高調** | 主面明度 60–85%;暗部不低於 ~35%;保留 3 階 shading(base/shadow/highlight) |
| G3 | **柔色輪廓(非純黑)** | 全遊戲棄純黑 `#000`/`#101018`/`#14121f` 輪廓;改用物件色**深一階染色**(描邊色=base 色的深版,可帶同色相)。角色不再有黑描邊。 |
| G4 | **大頭 Q 版比例** | 角色頭部佔高 40–50%、2 大眼、圓弧輪廓、短手腳;越萌越大頭 |
| G5 | **光源一致** | 左上受光:左/頂面亮於右/底面;單一 1px 高光點,不亂跳 |
| G6 | **無多點閃爍** | 每物件 1 顆小高光,避免多點高光閃爍 |
| G7 | **可讀性為上限** | 全彩度 ≤90%;繽紛 ≠ 刺眼;任何改動不得損數字/字/名牌/熱區可讀性 |

## 分域細則

### 村莊 / 王國場景(主頁村莊框為唯一村莊主場景)
- 保留村莊框機械規則:CELLS 座標契約、名牌/熱區/鎖定遮罩、每日寶箱(v627 遷入村莊框右下)等**機械規則**。
- 美術文法為 **SR 可愛糖果風**:
  - 建築 3 部件化保留(牆+屋頂+裝飾),但改用**高彩糖果色 + 柔色輪廓**,
    不再用 TheoTown 降飽和深綠貼地/U 字文法。
  - 大平面加同色系 1px 明暗點(保留 R6 級雜訊,打破平塗),色票改糖果系。
  - 貼地斜影保留(1–2px,可改柔色),但禁純黑影。
- **強制斬斷(TheoTown 專屬文法全刪)**:`#7a9a3a` 草綠校準、60–80% 降飽和、
  深綠貼地、等角 iso 文法、「左亮右暗」之外的 TheoTown 特有 R3/R4 規則不再適用。

### 角色 / 怪獸(取代 FF1 黑描邊)
- 大頭 Q 版(G4);2 大眼、圓弧、糖果色票。
- 黑描邊移除 → **G3 柔色染色輪廓**(取代原 `#14121f` 黑描邊)。
- 保留 16×16 格式、frame/rate/anchor 契約、motion frames(idle/walk/attack/hurt)。

### UI(取代 dark-fantasy 深色框架)
- 根背景/面板由深藍黑(*#141524/#1e2035*)轉**明亮糖果底**(奶油/天空藍/薄荷,高調)。
- 保留:稀有度色、金幣/寶石/榮譽 icon 識別、2px offset shadow 按鈕、8px radius、zh-TW。
- 對比契約(G7)優先:文字/數字/名牌不得因變亮而失可讀性。

## 色票規則(R 級,全域)

| # | 規則 | 數值/做法 |
|---|---|---|
| R1 | 主角物件飽和 65–90% | 糖果粉/陽光黃/薄荷/天空藍檔 |
| R2 | 主面明度 60–85%、暗部 ≥35% | 3 階 shading 不變 |
| R3 | 柔色染色輪廓 | 描邊=base 色深一階(同色相),禁純黑 |
| R4 | 左上受光、單高光 | 光源一致 |
| R5 | 大眼睛+圓潤 | 頭佔高 40–50%,2 大眼 |
| R6 | 大平面同色系雜訊 | 1px 明暗點,非平塗 |

## 比例規則(Q 版)

| 物件 | 頭部佔高 | 備註 |
|---|---|---|
| 獵人/流浪英雄 | 40–50% | Q 版大頭 |
| 怪獸/首領 | 30–40% | 呆萌;BOSS 保留體積壓迫感 |
| 裝飾/寵物 | 50%+ | 越萌越大頭 |
| 建築/地標 | 3 部件 | 高彩糖果,柔色輪廓 |

| 部位 | 配方 |
|---|---|
| 皮膚 | 底 `#ffd6a8` → 亮 `#ffe6c8`/暗 `#e8a070`,腮紅 `#ff9db0` |
| 髮/鎧/武 | 莓紅 `#ff6f8a`/檸檬 `#ffd166`/薄荷 `#7fd8c0`/紫 `#b48cff`/糖果金屬 `#ff9dd2` |
| 怪獸 | 高彩單色:史萊姆綠 `#7de86a`、糖果粉 `#ff6fae`、天空藍 `#6ac8ff`,3 階 |
| 屋頂/牆 | 糖果紅瓦 `#ff7a6a`、糖果藍瓦 `#6ac8ff`,交錯明暗 + 雜訊 |

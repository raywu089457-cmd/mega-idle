## 0. 一句話總覽

**掛機獵魔村經營 RPG**：每秒 1 tick；獵人派去 7 張獵場地圖打回合制戰鬥賺金幣/經驗/魔核/裝備；村莊 13 棟建築被動產出資源、藥水、裝備；流浪獵人會進村消費（村莊金庫收入）；擊敗最終 Boss 後可「重建村莊」拿傳承碎片並選擇累積型村莊傳統（Prestige 循環）。

```
每秒 tick → 公會整理素材 + 市集產金幣 + 煉金工房產藥水/商店補貨
        → 流浪獵人造訪 / 招募 → 派遣狩獵（驅逐/討伐/獵殺/頭目）或 4 人組隊連戰
        → 回合制戰鬥（技能/元素相剋/Boss 機制）→ 金幣/經驗/魔核/裝備掉落
        → 鐵匠鋪與皮甲工坊製作裝備 → 強化 +1..+10 → 提升獵人星級成長/特質/轉職
        → 成就永久加成 → 擊敗魔域大君 → 無盡深淵 + 重建村莊（傳承碎片 + 傳統）
```

## 3. 獵人系統

### 3.1 職業與轉職
- 5 基礎職業（data.js `HERO_CLASSES`）：劍士(HP100/ATK15/DEF10)、咒術師(70/25/5)、刺客(85/18/8)、遊俠(80/20/7)、神官(90/10/15)。
- Lv20 + 20💠 永久轉職（`ADV_CLASSES`）：聖騎士(HP+20%/DEF+15%)、大魔導(ATK+20%/魔核+10%)、影刃(ATK+10%/暴擊+8%)、神射手(ATK+15%/暴擊+5%)、主教(HP+15%/DEF+10%)；繼承原職技能樹與裝備限制（`baseClassOf`）。

### 3.2 屬性公式（`getHeroStats`，heroes-stats.js:40-101）
```
atk = (baseAtk + (Lv-1)×3 + 鐵匠Lv + 成就atk + 裝備atk) × 星級 × 特質 × 轉職% × 被動技能 × 疲勞
def = (baseDef + (Lv-1)×2 + 皮甲Lv + 成就def + 裝備def) × 同上
maxHp = (baseHp + (Lv-1)×10 + 裝備hp) × 同上
基礎暴擊 5%；疲勞 ≥70 → ×0.85、≥90 → ×0.7；起霧 魔核+10%；下雪 經驗×1.1
```
- **升級**：`xpNeed(Lv) = 80 + (Lv-1)×60`；每級成長 `×(1+(★-1)×0.12)`、HP 全滿、+1 AP。無等級上限。
- **訓練**：花金幣 `round((80+Lv×60)×(1+(★-1)×0.25))` 換 `50+Lv×15` XP。
- **星級**：招募 roll（1★5% / 2★20% / 3★45% / 4★22% / 5★8%）；星級乘數 `1+(★-3)×0.08`（1★×0.84、5★×1.16）。
- **稀有度**（與星級獨立 roll）：普通60/稀有28/英雄10/傳說2；只影響流浪獵人錢包倍率（1/1.3/1.8/2.6）與外框。
- **特質**（6 種）：鷹眼暴擊+4% / 鐵壁防+8% / 迅捷攻+6% / 財迷金幣+8% / 學者經驗+8% / 強韌HP+10%。Lv15 自動覺醒第二特質槽；重骰 2💠/次（排除現有）。
- **疲勞/狀態**：探索 +3/tick（Boss +4）、狩獵 +9/殺、休息 -18/tick、酒館 -22/次、閒置 -4/tick；疲勞 ≥90 且開啟 autoRecall → 自動召回。休息回血 `ceil(maxHp×0.25×(1+旅館Lv×0.1))`。
- **藥水**：治療 30% maxHp；血量 <35% 且 autoPotion 開啟 → 戰鬥中自動喝。

## 4. 技能樹（每職業 5 技：3 被動 + 2 主動）

- **AP**：僅升級 +1/級；學習 1 AP/級（被動上限 5 級、主動上限 3 級）；**洗點 5💠 全返還**。無前置限制（扁平樹）。
- 主動技：每回合 40% 觸發率、冷卻 = `triggerRounds` 回合、持續型掛 `skillBuffs`；例：劍士 怒斬(暴擊+30%/級 5回合 CD8)、狂暴(攻+25%/級 3回合 CD10)；咒術師 烈焰(+40%/級 CD9)、寒冰(+20%/級+凍結2回合 CD7)；刺客 背刺(必暴擊+25%/級 CD6)、疾風(二連擊 CD8)；遊俠 鷹眼(暴擊+35%/級 4回合 CD9)、貫穿(無視30%防/級 CD7)；神官 治愈(回25%/級 CD8)、懲擊(+30%/級 CD7)。
- 被動：攻/防/HP/暴擊/閃避/魔核/金幣/經驗百分比疊加（詳見 data.js `SKILL_TREE`）。

## 5. 裝備與道具

- **三槽**：武器（職業綁定）、防具、飾品（通用）；全部**實例制** `{iid, id, tier, affix, plus, name, icon}`。
- **品質 roll**：普通 60% / 精良 15%（×1.15）/ 傳說 10%（×1.30）；商隊事件時精良/傳說 +15% 門檻。**詞綴**：傳說必帶、精良 40%（吸血擊殺回4% / 獵手對王+12% / 學者經驗×1.1 / 尋寶魔核+8% / 荊棘反彈8%）。
- **強化**：+1..+10 必成功；`金幣 max(10, round(120×(plus+1)×(1-強化爐Lv×0.06)))` + `魔核 floor((plus+1)/2)`；每級 武器atk+3、防具def+3/hp+15、飾品atk+2/hp+8/暴擊+0.015。
- **套裝**：2 件套（獵魔/屠魔/見習/野獸）與 3 件套（龍鱗/虛空/影行者/十字軍/神射手套），湊齊自動生效（`applySetBonuses`）。
- **製作**：約 40 種道具（data.js `ITEMS`），鎖建築等級（T5 神話裝需 鐵匠14 + 祭壇10）；消耗素材+金幣+魔核。
- **處理管道**：販賣（傳說×2.5/精良×1.5 價）、一鍵賣普通、分解（返 50% 素材；傳說 100%→3💠、精良 80%→1💠）、轉化（換魔核+金幣，套裝件 +1💠）。
- **商店**：玩家可調價格 0.8/1.2/1.6 倍影響獵人購買；村莊收入入 `stats.shopRevenue`。
- **委託訂單**：每 5 分鐘生成限時訂單（3 分鐘時限、1.5× 售價），交付品質加成（精良 ×1.2 / 傳說 ×1.5）。
- 倉庫上限 100（`MAX_INV`）。

## 6. 戰鬥系統

### 6.1 單人即時戰（`advanceLiveCombat`，1 tick = 1 回合，可 1×/2×/4× 加速）
- **傷害公式**：`base = max(1, atk - def×0.55)`；`dmg = base × rand(0.85,1.15) × (暴擊?1.7:1)`；暴擊率基礎 5%；敵反擊暴擊固定 3%。
- 回合序：冷卻遞減 → 第 30 回合 Boss 狂暴(×2) → 自動藥水(<35% HP) → 主動技 40% roll → 我方攻擊（×元素相剋 1.25、×技能加成、×Boss護盾、×對王傷）→ 二連擊 → 治療/凍結 → **Boss 50% 血二階段(攻×1.3)** → 敵反擊（閃避判定、荊棘反彈）。
- **元素相剋**（武器元素 → 克制區元素 +25%）：雷>土、毒>自然、自然>毒、冰>火、聖>暗；**五種區域元素皆有剋星**（例：熔岩裂谷 火 ← 咒核法杖 冰；魔域 暗 ← 聖印戰錘/十字戰錘 聖）。
- **Boss 機制**（每區一個，solo 數值）：regen 每5回+15% / poison 每3回毒8% / shield 前15回承傷×0.5 / lifesteal 反擊吸血80% / aoe 每6回無視防禦25% maxHp。
- **同區編隊加成**：同難度盟友每多 1 種職業 +5% 攻（`partyInfoFor`）。
- **夜間**：場景夜晚（10 分鐘週期約 55% 時間）掉落率 0.28→0.38。
- **回合上限 60** → 疲勞撤退（`round>=60`）；戰敗 20% HP 回村、休息 6 tick。
- **掉落**：魔核機率全區 1.0（必掉）；裝備/藥水照 `drops` 表。
- **派遣**：需 疲勞<90、非探索/休息中；Boss 需三難度全清；帶 `min(2, 藥水數)` 藥水；記住上次派遣地（一鍵再出發/全隊召回）。

### 6.2 組隊戰（`advancePartyCombat`，4 常駐隊伍 × 4 人）
- 全隊打**同一隻敵人**（共享血條）；前→後排輪流出手；**前排 70% 被鎖定、後排承傷 -30%、輸出 -10%**；每多 1 名成員 +10% 總攻。
- 技能/元素/套裝/詞綴/Boss 機制全生效（party 版數值較輕：護盾前10回×0.6、regen 8%、毒全體5%、aoe 全體20%）。
- **連戰**：常駐隊伍非頭目勝利 → 陣亡者 20% HP 脫隊回村 → 剩餘隊員整裝 12 tick → 隨機敵人續戰（streak+1）；全滅/疲勞→撤退；回合上限 80。
- **獎勵**：金幣 `rand(goldRange)×(1+0.25×(人數-1))`、每人各自經驗、掉落率 solo 一半但每人各 roll（4 人隊淨量 ≈ 2×）。
- ⚠ **差異**：組隊金幣不吃 `goldMult`、魔核不吃 `msFind`（combat-party.js:324,327）— 對王/財迷等加成在組隊戰失效。

### 6.3 離線戰（`runCombat`）
- 離線結算用：24 回合上限、同公式；探索中獵人離線每 30 秒結算 1 場（上限 24 場、首敗即停、每勝 +20 探索進度，上限 99）。

## 8. 流浪獵人與村莊生活（「獵人是顧客」經濟）

- **生成**：每 `max(2, 12-酒館Lv×2)` 秒 1 隻；上限 `10+(酒館Lv-1)×3`；15 種型態（3 階 × 5 職，Lv1-16）；權重 低等×10/中等×5/高等×1；稀有度 60/28/10/2；錢包 `round((40+Lv×60)×稀有度倍率)`；心情 50-80+min(15,Lv)、-0.1/tick。
- **需求 AI**（優先序）：心情<20 離村 → 低血/高疲勞/心情差 去酒館 → 缺藥去煉金 → 錢夠裝備差去鐵匠 → 選獵場（依等級帶 村郊1-5/霧林4-9/荒嶺8-14/虛空15+）即時打怪（賺自己的金幣、+9 疲勞/殺）。
- **消費**：餐/飲/藥/裝備費用入村莊金庫（`shopRevenue`）；商店同時只服務一位、其餘排隊（排隊中心情 -2/1.5s）。
- **招募**：費用 `60+Lv×45` 金（稀有訪客事件 -50%）；**招募前檢查空位**（`村莊空位 = 7+(酒館Lv-1)×2`，不足擋下並提示升級酒館）；成功轉為村莊獵人（Lv=型態等級）。
- 陣亡墓碑 18 秒後復活（旅館縮短 30%）；對話泡泡全 zh-TW。

## 9. Meta 系統

- **成就**（13 項，永久、跨重建）：首殺/百殺/五百殺/1 頭目/5 頭目/金幣 1 萬/10 萬/建築總級 15/30/點擊 100/1000/登入 7 天/重建 1 次；獎勵 = 素材%、金幣%、經驗%、點擊、atk/def 常數。
- **每日**：連登第 N 天 `金幣 150+N×60` +（每 3 天 1💠）+（藥水 1+floor(N/2)）；里程碑 7/14/30/60/100 天大量獎勵。
- **離線收益**：50% 效率、**上限 8 小時**；金幣=市集產率×秒×0.5、素材=2×公會Lv×秒×0.5×乘數、藥水照產率；探索中獵人自動結算遠征（§6.3）。
- **重建（Prestige）**：擊敗最終 Boss 後解鎖（code gate = zone 7 `finalBossDefeated`，meta.js:109；⚠ 教學文案寫 zone 5，見 §15）；傳承碎片 = `max(1, 1 + floor(Σ英雄等級/30) + floor(成就數/6))`；**每次重建選 1 個傳統（可疊加）**：
  - 商業傳統：商店營收 +25%/次
  - 鍛造傳統：精良/傳說率 +8%/次
  - 狩獵傳統：金幣/經驗/素材 +15%/次 ✅ **唯一已接線**
  - 學術傳統：經驗 +10% + 1 AP/次
  - 開拓傳統：Boss 前置放寬 1 階/次
  - 重置資源/建築/獵人/地圖；保留 stats/成就/傳統/每日/設定。碎片另計入點擊收益。

## 13. LLM 大腦模式（選配 AI 總管）

- 三模式：**mock**（本機規則 AI，離線免費）/ **cassette**（錄放回歸）/ **live**（Anthropic/OpenAI/Ollama/MiniMax，依 baseUrl 自動偵測）。
- 接管：流浪獵人決策（MOVE_TO/REST/LEAVE/HUNT enum）、對話泡泡、村莊八卦 rumor、戰鬥技能選擇（tactics）。
- 預算治理：預設 200k token/日；≥80% 節流只留 critical、≥100% 自動退回 mock；API key 只進 sessionStorage 不入存檔。
- 對玩法影響：mock 模式行為與既有 scene AI 完全等價；屬「可選風味層」。

## 15. 已知差異 / 未接線資料（抽取代價，供接手者注意）

1. **Nightmare 是死資料**：zone 5 `nightmare` 難度（魔域大君・冥影）與 zone 6/7 的 `unlockHeroLevel`（30/60）無任何 code 消費 — 但 zone 6/7 可經 Boss 鏈解鎖（等級門檻失效）。[grep 驗證]
2. **傳統只有 hunt 接線**：commerce/forge/scholar/pioneer 數值已定義，無消費者（`getTraditionBonus` 有值但 bonuses.js 只用 hunt；econ-sim 也只模擬 hunt）。
3. **護盾 Boss 三處數字不一致**：solo 前 15 回 ×0.5（combat.js:185）、party 前 10 回 ×0.6（combat-party.js:238）、教學文案「前 10 回合 -40%」（data.js BOSS_MECH_TEXT）。
4. **組隊戰不吃 goldMult / msFind**（combat-party.js:324,327）— 詞綴/傳統/祭壇加成在組隊戰失效。
5. **重建門檻**：code 用 zone 7 深淵之心（meta.js `finalBossDefeated` 取 `ZONES[ZONES.length-1]`），教學/文檔寫 zone 5 大君 — 實際解鎖比文檔晚。
6. **深淵無戰報**：`finishAbyssCombat` 不寫 battleReports；深淵走 `startLiveCombat` fallback hack（非正式 zone）。
7. **鍛造專精「完美爐 成功+10%」無意義**（強化本就必成功）。
8. 離線素材公式（2×公會Lv×秒×0.5）與在線（rand(1,4)×Lv×秒）不同步 — 離線較少。
9. 藥水產出註解寫「一半入倉庫、一半上架」，實作是全量同時入玩家倉庫與商店貨架（meta.js produceTick）— 玩家收益比設計意圖多一倍。

# TheoTown 畫風規則 — mega-idle 等角美術基準

> 來源:TheoTown 官方等角教學討論串(風格規則權威)、Plugin Creator/PCA 工具鏈規格。
> 適用:js/ui/map.js 全部繪製(地形/村莊/區域地標/模式地標/小人/裝飾)、
> 以及任何新繪製的等角資產。**每輪地圖美術改動必須通過下方驗收清單。**
> 適用範圍界定:本規則適用**地圖資產(建築/地標/地形/裝飾)**;
> **角色/小人維持 FF1 黑描邊契約**(v278 FF1 GBA 風格 — 黑描邊是角色識別特徵,不在此規則內)。
> **地圖小人協調註記**:drawTownie 等程序小人維持 FF1 黑描邊(識別特徵),但與無黑輪廓建築
> 並排時,描邊色建議用 `#1e1e28` 等級(略降對比,非純黑 `#14121f`)— 讓小人與建築同框時
> 風格協調、不致「貼紙感」;此為建議非強制(角色契約優先)。

## 1. 色票規則(最高優先)

| # | 規則 | 數值/做法 |
|---|---|---|
| R1 | 飽和度 60–80% | 不要過艷(>85%)也不要發灰(<50%);校準:與草地 #7a9a3a 同檔 |
| R2 | 明度 70–80% | 主面中高明度;暗部(底面/背光)不低於明度 ~30% |
| R3 | **不用全輪廓線** | 地圖資產禁止純黑 `#000`/`#101018` outline;改用品項同色系深一階色 |
| R4 | 左緣/頂緣受光 | 光源固定左上:左面+頂面亮一階,右面+底面暗一階 |
| R5 | 牆底漸暗 | 牆底 1–2px 深一階色帶(接地感,非陰影) |
| R6 | 平面加同色系雜訊 | 大平面(牆/屋頂/地面)加 1px 同色系明暗點,打破平塗 |

## 2. 比例規則(人物 3px 高為基準)

| 物件 | 高度(px) | 對照 |
|---|---|---|
| 柵欄/灌木 | 1–2 | 半人高 |
| 攤位/矮棚 | 6–9 | 2–3 人高 |
| 小屋/商店 | 10–16 | 3–5 人高 |
| 2 層建築 | 16–24 | 5–8 人高 |
| 高塔/城堡 | 30+ | 10+ 人高 |

- 門 = 1 人高(3px);窗 = 1–2px;屋頂佔總高 1/3–1/2
- 建築寬度 ≈ 高度 × 2(等角視覺平衡)

## 3. 結構規則(部件化)

- 等角 tile 菱形基準:寬:高 = 2:1(本遊戲 TW=32/TH=16 ✓ 已是)
- 建築至少 **3 部件**:牆 + 屋頂 + 至少一個裝飾(門/窗/旗/煙囪/台階)
- 必須有:貼地斜影(1–2px,右下方)、台階/基座、屋簷投影
- 地面 tile 邊緣:同色系深一階細線,禁止黑線

| 材質 | 配方 |

| 紅瓦屋頂 | 底 #c8402f → 每行交錯 #a03020/#d84a38,屋脊亮 #e06048 |
| 茅草屋頂 | 底 #c8a060 → 雜訊點 #a08040/#e0c080,邊緣鋸齒狀 |
| 石板牆 | 底 #8a8a9a → 隨機塊 #7a7a8a/#9a9aaa,縫線 #6a6a7a |
| 木牆 | 底 #8a5a2a → 直紋 #6a4020,節點 #5a3018 |
| 磚牆 | 底 #a06048 → 交錯磚 #8a4a38/#b87058,縫 #7a4030 |
| 植被 | 3 階:深 #2a4a2a / 中 #3a6a3a / 亮 #4c8a3f(點綴) |
| 水 | 底 #1a2a4a → 波紋 #2a4a7a/#3a6a9a(1px 閃爍) |
| 金屬 | 底 #9a9aa8 → 高光 #c0c0d0 左上 1px,暗 #7a7a88 右下 |

## 5. 驗收清單(每輪地圖美術改動必測,全過才算完成)

- [ ] 地圖資產無純黑輪廓線(搜尋 `#000`/`#101018` — 角色/UI 除外)
- [ ] 光源一致:所有部件左/頂面亮於右/底面
- [ ] 主色飽和度 60–80%、明度 70–80%
- [ ] 有貼地斜影(1–2px)
- [ ] 至少 3 部件(牆+屋頂+裝飾)
- [ ] 比例符合人物 3px 基準表
- [ ] 大平面有同色系雜訊(非平塗)
- [ ] 截圖證據:新資產與既有地標(風車/冰塔)並排,風格同源可辨

# 放置王國 MEGA IDLE — 長期改善日誌(製作人輪換制)

> 製作人輪換制:每輪依序 **玩法機制與耐玩性 → UI/UX 與品質 → 等角地圖 → 動作與戰鬥呈現 → 數值平衡與留存**,五主題輪完循環數 +1。
